- Break and continue

  In Python,`break`and`continue`It's two key words to control the flow. They can help you to end the cycle early or skip the current iterative under certain conditions.

  - **`break`Statement**
    - Stop the current cycle immediately (`for`or`while`）
    - Once out of the loop, the program will continue to execute the code after the cycle
    
    - ** Example:**
      ```python
      # 找到第一个偶数后立即终止循环
      numbers = [1, 3, 5, 8, 9, 10]
      for num in numbers:
          if num % 2 == 0:
              print(f"找到偶数:{num}")
              break  # 终止循环
          print(f"当前数字:{num}")
      
      print("循环结束")
      ```
      **Output**
      ```
      当前数字: 1
      当前数字: 3
      当前数字: 5
      找到偶数: 8
      循环结束
      ```

  - **`continue`Statement**
    - Skip the remaining code of the current cycle immediately
    - Go straight to the next cycle.
    
    - ** Example:**
      ```python
      # 只打印奇数，跳过偶数
      numbers = [1, 2, 3, 4, 5, 6]
      for num in numbers:
          if num % 2 == 0:
              continue  # 跳过偶数
          print(f"奇数: {num}")
      
      print("循环结束")
      ```
      **Output**
      ```
      奇数: 1
      奇数: 3
      奇数: 5
      循环结束
      ```
  
  - **Application in embedded loops**
    `break`and`continue`Only affect the current inner circle:
    
    ```python
    for i in range(3):
        print(f"外层循环 {i}:")
        for j in range(3):
            if j == 1:
                break  # 只跳出内层循环
            print(f"  内层循环 {j}")
    ```
    **Output**
    ```
    外层循环 0:
      内层循环 0
    外层循环 1:
      内层循环 0
    外层循环 2:
      内层循环 0
    ```

** Summarized: break ends the current cycle, continue ends the cycle**
