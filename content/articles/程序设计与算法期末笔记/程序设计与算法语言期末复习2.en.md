## Object-oriented (OOP)

### Python For Object
```python
class Employee:
    # __init__构造函数
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    # 定义函数时要传入self参数    
    def getName(self):
        return self.name
    
    def getSalary(self):
        return self.salary
    
    # 定义比较函数，将name作为比较对象
    def __lt__(self, other):
        return self.name < other.name

    # __repr__对应java中的toString()，用于返回对象表示形式（打印一个对象会默认返回其地址）
    def __repr__(self):
        return 'An employee {} whose salary is {}.'.format(self.name,self.salary)
```

Sort in main function with sort function:

```python
hanmei = Employee('Han Mei', 10000)
lilei = Employee('Li Lei', 8000)
tom = Employee('Tom', 50)
staff = [hanmei, lilei, tom]
# 默认按照Employee中__lt__方法，按名字排序
staff.sort()
# 也可使用Lambda表达式，自定义排序方式
staff.sort(key = lambda c:c.salary) # 默认升序
staff.sort(key = lambda c:c.salary, reverse = True) #reverse = True 降序
print(staff)
```

class Athlete implements Comparable<Athlete> {
    private String name;
    private int height;
    private int weight;
    private double salary;

    public Athlete (String name, int height, int weight, double salary) {
        this.name = name;
        this.height = height;
        this.weight = weight;
        this.salary = salary;
    }

    public String getName() {
        return name;
    }
    public int getHeight() {
        return height;
    }
    public int getWeight() {
        return weight;
    }
    public double getSalary() {
        return salary;
    }

    @Override
    public String toString() {
        return String.format("An Athlete %s with height of %d and weight of %d", getName(),getHeight(),getWeight());
    }

    @Override
    public int compareTo(Athlete o) {
        return name.compareTo(o.name);
    }
}

class BasketballPlayer extends Athlete {
    private int shootLv;
    private double ticketprofit;

    public BasketballPlayer(String name, int height, int weight, double salary, int shootLv, double ticketprofit) {
        super(name, height, weight, salary);
        this.shootLv = shootLv;
        this.ticketprofit = ticketprofit;
    }

    public int getShootLv() {
        return shootLv;
    }
    public double getTicketprofit() {
        return ticketprofit;
    }

    @Override
    public String toString() {
        return String.format("An basketball player %s with shooting level %d", getName(),getShootLv());
    }

    public int compareTo(Athlete o) {
        BasketballPlayer b = (BasketballPlayer)o;
        return shootLv - b.shootLv;
    }
}

## Use of the Python Standard Library and Java Outer Library, as required

### Python
#### Math library
- Import
  ```python
  import math
  ```

- Basic Math Functions
  - `math.sqrt(x)`: Calculate square root, if`math.sqrt(16) → 4.0`  
  - `math.pow(x, y)`: the y-decided to calculate x, if`math.pow(2, 3) → 8.0`  
  - `math.exp(x)`: x-decided to calculate e, if`math.exp(1) → 2.71828...`  
  - `math.log(x, base)`: Calculate logarithm, default is e-based, as if`math.log(100, 10) → 2.0`

- Triangular Functions
  - `math.sin(x)`Sine (radians)
  - `math.cos(x)`Cosine (radians)
  - `math.radians(deg)`Angle radians, if`math.radians(180) → 3.1415...`
  - `math.degrees(rad)`: radians turning angles, if`math.degrees(math.pi) → 180.0`

- Special constant
  - `math.pi`：π（3.14159...）
  - `math.e`: Natural constant e (2.71828...)
  - `math.inf`('inf')
  - `math.nan`Non-value ( 'nan')

#### Brandom Library
- Import
  ```python
  import random
  # 或
  import random as r
  # 或
  from random import *  # 导入内部所有功能，后续可以直接使用
  ```

- Basic random number generation
  - `random.random()`: Random floats within [0.0, 1.0) generation
  - `random.uniform(a, b)`: Generate random floats within [a, b] range
  - `random.randint(a, b)`: Generate a random integer within [a, b] range (includes a and b)

- Sequence Operations
  - `random.choice(seq)`: random selection of an element from a sequence (e.g., list, group)
  - `random.choices(seq, weights=None, k=1)`: k elements are randomly selected with release Heavy
  - `random.sample(seq, k)`: random selection of k elements without release, without repetition
  - `random.shuffle(seq)`: In situ disruption of sequence (only for variable sequences, e.g., list)
