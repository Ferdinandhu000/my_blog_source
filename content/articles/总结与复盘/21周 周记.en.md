## Blog Building Sharing

- Building a blog website was the result of a series of coincidences. I thought about giving up several times along the way, but I'm glad I stuck with it. Nowadays, the blog content is gradually enriching and I'm using various methods to help build my blog. 

### Static Web Page Generator
- In simple terms, it means converting the content you want to show on your blog into HTML language to display it on a webpage. Here, I am using the **Hugo** static site generator. Other mainstream options currently include **Hexo**.
- All blog content in Hugo supports writing with Markdown syntax, and the converted HTML will be stored in the public folder.

### Git
- **GitHub** provides each registered user with a dedicated default URL in the format `(username).github.io`. Therefore, you can upload the relevant content of your blog to a GitHub repository and access your blog through the default domain. For specific operations, you can refer to the video by [Zuo-Lan](https://space.bilibili.com/27619688), which provides a very detailed full process of setting up a blog.
- Of course, you can also change your own website URL. Here, I recommend using the [**Netlify**](https://app.netlify.com/) website service platform to change your domain name.
- Hugo has a very clear file management system. In the Terminal, you can enter the command `Hugo new folder_path/filename.md` to create a blog file in markdown format. At the same time, you can execute the `Hugo server` command to view the website's build status locally. After confirming everything is correct, use the Hugo folder as a local repository and execute git commands to upload the files to the GitHub remote repository.

### Tool Recommendations

#### [Cursor](https://www.cursor.com/)
- Although it seems unrelated to this part, I still want to introduce this very powerful AI code editor. In addition to the regular code completion features, Cursor can also generate code based on the user's natural language descriptions. Cursor can be seen as a code editor like VSCode, with its code completion and generation features directly integrated into the code area, without the need for copy-pasting or other operations.

#### [Obisidian](https://obsidian.md/)
- Currently, I am actually using Obsidian to write my current blog. **Obsidian** is an open-source and highly versatile note-taking software that perfectly supports **Markdown** syntax and has a rich plugin ecosystem.
- Previously, I was writing and publishing my blog in **VSCode**, but in VSCode, I couldn’t preview the content in real-time. Obsidian perfectly solves this problem and also adds rich features such as backlinks to assist writing, greatly improving writing efficiency.
