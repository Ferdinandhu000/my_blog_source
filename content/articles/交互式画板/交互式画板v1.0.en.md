## Interactive Drawing Board v1.0

---
Implement a simple interactive drawing board using Java

### Introduction to the functions of each class
1. `DrawPad` class: Basic window setup and visualization, and adding mouse and keyboard listeners to the window
2. `MouseListener` class: Create a listener class that implements the mouse listener, implementing methods such as mouse click, press, release, enter, and exit.
3. `KeyListener` class: Create a listener class that implements a keyboard listener, making it convenient to control and switch between different drawing types on the keyboard

---

6. Using the same method, create a keyboard listener `KeyListener` class to facilitate controlling and switching between different painting types. In the keyPressed method block:
```java
public class KeyListener implements java.awt.event.KeyListener {
    // 声明一个私有的 MouseListener 类型的成员变量 mouseListener，用于引用一个 MouseListener 对象，以便在键盘事件处理中与鼠标事件相关联
    private MouseListener mouseListener;

    // 定义类的构造方法，接收一个 MouseListener 类型的参数 mouseListener
    public KeyListener(MouseListener mouseListener) {
        this.mouseListener = mouseListener;
    }
    public void keyTyped(KeyEvent e) {
        System.out.println("输入：" + e.getKeyCode());
    }

    public void keyPressed(KeyEvent e) {
        System.out.println("按下：" + e.getKeyCode());
        int keyCode = e.getKeyCode();
        // 使用 switch 语句根据不同的键码执行不同的操作
        switch (keyCode) {
            case KeyEvent.VK_1:
                // 调用 mouseListener 对象的 setDrawType 方法，将绘画类型设置为 1
                mouseListener.setDrawType(1);
                System.out.println("当前绘画类型：直线");
                break;
            case KeyEvent.VK_2:
                mouseListener.setDrawType(2);
                System.out.println("当前绘画类型：矩形");
                break;
            case KeyEvent.VK_3:
                mouseListener.setDrawType(3);
                System.out.println("当前绘画类型：实心矩形");
                break;
            case KeyEvent.VK_4:
                mouseListener.setDrawType(4);
                System.out.println("当前绘画类型：等腰三角形");
                break;
            case KeyEvent.VK_5:
                mouseListener.setDrawType(5);
                System.out.println("当前绘画类型：五角星");
                break;
        }
    }

    public void keyReleased(KeyEvent e) {
        System.out.println("松开：" + e.getKeyCode());
    }
}
```
