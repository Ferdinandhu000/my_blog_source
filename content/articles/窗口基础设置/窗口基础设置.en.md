## Window Foundation Settings

---
### Principle:
It's from the Java outer library.`java.awt`and`javax.swing`Packages implemented

---
### Basic steps:
1. Create a new class (e.g.`LoginUI`）
2. Define a method in this category (e.g.`showUI()`, for development interface)
3. Import`java.awt`and`javax.swing`Two interface development packages
4. Create a main function at the end`main`in which you can create`LoginUI`object (e.g.`u`(i) and call before`showUI()`methodology)
---
### Details
- Use`import`statement imports two interface development packages, end of ... * for all of the packages imported Category
```java
import java.awt.*;
import javax.swing.*;
   ```
- Creating defined methods`showUI()`Then you can create a form object`jf`, with the imported`javax.swing`Create JFrame
```java
JFrame jf = new JFrame();
```
- Set the properties of the form
```java
jf.setTitle("登录窗口"); //设置窗口标题
jf.setSize(400, 500); //设置窗口大小
jf.setLocation(600, 200); //设置窗口位置
jf.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); //点击关闭按钮时，java程序终止
```
- Set Layout in Window
  - Create layout object first (use here)`java.awt`In the bag.`FlowLayout`Class created)
  ```java
  FlowLayout fl = new FlowLayout();
  ```

  - Add a picture (need to pass it to Label)
  ```java
  ImageIcon img = new ImageIcon(<图片文件地址>);
  JLabel imgJla = new JLabel(img);
  ```
  - Add Label (Text)
  ```java
  JLabel nameJla = new JLabel("账号：");
  JLabel pwdJla = new JLabel("密码：");
  ```
  - Add single line text input box
  ```java
  JTextField nameJtf = new JTextField(35); // 输入框可以显示30个字符宽度，每个字符约10像素
  ```
  - Add button
  ```java
  JButton loginBtn = new JButton("登录");
  ```
- Add all the layout components created above to the form object`jf`Medium
```java
jf.add(imgJla);
jf.add(nameJla);
jf.add(nameJtf);
jf.add(pwdJla);
jf.add(pwdJtf);
jf.add(loginBtn);
```
- Visualise
```java
jf.setVisible(true);
```
