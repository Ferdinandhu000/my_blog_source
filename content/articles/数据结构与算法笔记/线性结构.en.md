## Linear Table

[Case] Multiple expression

- Method I: The sequenced storage structure is directly expressed
  Subscript i: Index
  a [i]: coefficient for entry
  Analyze: For example,$x+3x^{2000}$It's a multi-form, it's a waste of storage and operation.

- Method II: sequential storage structures represent**non-zero items**
  Subscript i (ordered by index size)
  coefficient$a^i$
  Index i
  Think of it as one.$a_i$(i) Binary assembly
  Two multi-dimensional additions can follow.

- Method III: Chain structure stored non-zero items

  ```CPP
  typedef struct PolNode *Polynomial;
  struct PolyNode {
    int coef;
    int expon;
    Polynomial link;
  }
  ```

### Linear List

- Composition: Data element & sequence
- Operating set:
  - List MakeEmpty(): Initialize an empty linear table L
  - ElementType FindKth(int K, ListL): returns the corresponding element according to order K
  - Int Find (ElementType X, ListL): Find the first occurrence of element X in L
  - void Insert (ElementType X, int i, List L): Insert a new element X before the place i
  - void Delete(int i, List L): clears the elements of the given location
  - Int Length(ListL): Returns the length of Ln
- Ordered storage achieved: using arrays
