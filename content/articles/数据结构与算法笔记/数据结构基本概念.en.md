## Online processing algorithms

```CPP
int MaxSubseqSum( int A[], int N )
{
  int ThisSum, MaxSum;
  int i;
  ThisSum = MaxSum = 0;
  for( i = 0; i < N; i++) {
    ThisSum += A[i];
    if( ThisSum > MaxSum ) {
      MaxSum = ThisSum; // 找到了更大的子列，更新MaxSum
    }
    else if (ThisSum < 0) {
      ThisSum = 0; // 当前子列和小于零，在此基础上不可能让最终的子列和更大，故舍弃之
    }
  }
}
```
