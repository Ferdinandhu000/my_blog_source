## Sorting algorithms

### Bubble Sort

#### Thinking.
From i = 0, the numbers marked below i and i +1 are compared each time, and if the former are larger, the two are exchanged and ultimately located at the end of the column in the largest of the current cycle

#### Code
```java
public static void bubbleSort(int[] arr) {
   int n = arr.length;
   for(int i = 0; i < n-1; i++) {
       for(int j = 0; j < n-i-1; j++) {
           if(arr[j] > arr[j+1]) {
               int temp = arr[j];
               arr[j] = arr[j+1];
               arr[j+1] = temp;
           }
       }
   }
}
```

#### Complexity analysis
- Time complexity:$O(n^2)$
- Space complexity:$O(1)$

### Select Sorting
#### Thinking.
The smallest (or maximum) element is found in each round of parts that have never been sorted and placed at the end of the sorted part. This is done by identifying the subscript of the minimum value from i to the end of the array, assuming the current treatment of i-location, and then swapping it with i-elements. So each round can determine the final location of an element until it's all in order.

#### Code
```java
public static void selectionSort(int[] arr) {
    int n = arr.length;
    for(int i = 0; i < n-1; i++) {
        int min_idx = i;
        for(int j = i + 1; j < n; j++) {
            if(arr[j] < arr[min_idx]) {
                min_idx = j;
            }
        }
        if(min_idx != i) {
            int temp = arr[min_idx];
            arr[min_idx] = arr[i];
            arr[i] = temp;
        }
    }
}
```

#### Complexity analysis
- Time complexity:$O(n^2)$  
- Space complexity:$O(1)$  

### Insert Sort
#### Thinking.
Starting with the second element (index 1), treats the current element as an " element to be inserted " , and compares the sequence to the left that has been sorted from the right to the left, moving any element larger to one to the right until the first position is found, and the element is inserted into that position. Repeat this process and gradually expand the sorted range to the right

#### Code
```java
public static void insertionSort(double[] a) {
    int n = a.length;
    for(int j = 1; j < n; j++) {
        double key = a[j];
        int i = j - 1;
        while(i >= 0 && a[i] > key) {
            a[i+1] = a[i];
            i--;
        }
        a[i+1] = key;
    }
}
```

#### Complexity analysis
 - Time complexity: average/worst$O(n^2)$Better.$O(n)$
 - Space complexity:$O(1)$

### Grouping (Merge Sort)
#### Thinking.
Adopt a partitioning strategy: divide the clusters backwards into two groups, sorting each of the left and right sub-groups; then combine the two sequenced sub-numbers in a linear manner at the consolidation stage and form an orderly number Group

#### Process
1. Recursively handle the left half
2. Recursively handle right half
3. Merge
    - Either the left or the left are written in the L., the R. Medium
    - Initialization of two pointers i, j to the first of L, R, and then to the larger, write to the original array and move the pointer to the right

#### Code
```java
public static void mergeSort(double[] a, int p, int r) {
    if(p >= r) return;
    int q = (p + r ) / 2;
    mergeSort(a, p, q); // 递归处理左半边
    mergeSort(a, q + 1, r); // 递归处理右半边
    
    merge(a, p, q, r); // 合并操作
}

public static void merge(double[] a, int p, int q, int r) {
    int n1 = q - p + 1;
    int n2 = r - q;
    double[] L = new double[n1 + 1]; // 在末尾加上一项正无穷，故要加1
    double[] R = new double[n2 + 1];
    // 将左半边数据存入L数组中
    for(int i = 0; i < n1; i++) {
        L[i] = a[p + i];
    }
    L[n1] = Double.POSITIVE_INFINITY;
    // 将右半边数据存入R数组中
    for(int j = 0; j < n2; j++) {
        R[j] = a[q + 1 + j];
    }
    R[n2] = Double.POSITIVE_INFINITY;
    // i, j指针指向R, L两数组中的元素进行比较
    int i = 0, j = 0, k = p;
    while(k <= r) {
        if(L[i] <= R[j]) a[k++] = L[i++];
        else a[k++] = R[j++];
    }
}
```

#### Complexity analysis
 - Time complexity:$O(n\log n)$
 - Space complexity:$O(n)$


### Quick Sort (Quick Sort)
#### Thinking.
Separation and in situ division: select a pivotal axis (e.g., end element) and divide arrays by a single scan. "<= 枢轴”和“>The two components of the axis, which are in position; the regression is fast-sorted on both sides of the sub-array.

#### Process
1. Select the axis (this achieves the end element)
2. Linear scanning and division: maintenance pointer i Recording "< = pivotal axis" at the end of the zone, scanned pointer j all over [p, r-1]
   **Note i Originally p - 1, j to p**
   - If a [j] < = axis, i Forward and exchange a [i], a [j]
3. Swap a [i+1] axis after scanning, position the axis and get partition q = i + 1
4. Recursively handle left slots [p, q-1] and right slots [q+1, r]
   ** Note not including q position**

#### Code
```java
public static void quickSort(double[] a, int p, int r) {
    if(p < r) {
        int q = partition(a, p, r);
        quickSort(a, p, q - 1);
        quickSort(a, q + 1, r);
    }
}
public static int partition(double[] a, int p, int r) {
    double x = a[r];
    int i = p - 1; // 注意这里i取初始下标-1
    for(int j = p; j < r; j++) {
        if(a[j] <= x) {
            i += 1;
            swap(a, i, j);
        }
    }
    swap(a, r, ++i); // 这里为了简写使用前++，因此后一行返回的i为加一后的i
    return i;
}
public static void swap(double[] a, int i, int j) {
    double temp = a[i];
    a[i] = a[j];
    a[j] = temp;
}
```
#### Complexity analysis
 - Time complexity: average$O(n\log n)$;worst$O(n^2)$
 - Space complexity:$O(\log n)$


### Stack Sorting (Heap Sort)
![](https://raw.githubusercontent.com/Ferdinandhu000/my_blog_img/master/20251228152613.png)

#### Prior knowledge
- Two fork after tree: full fork tree. All but the last layer is filled and the last layer is left-handed as far as possible.
- Stacks: an array storage structure based on a full diagonal tree; the maximum stack meeting any node is not less than its subnode; the smallest stack is the opposite.
- Paternity: Under 0 base index, parent(i)=(i - 1) / 2.
- Root node: Under the 0 base index, root is marked below 0.
- Sub-point: Under 0-base index, left(i) = 2i + 1, right(i) = 2i + 2.
- Leaf nodes: No child nodes. In the base index, i n/2 is a leaf node.

#### Thinking.
Builds the maximum stack, making the top the maximum of the current range; trades the top with the last element, reduces the active stack space and then re-establishs the heapy properties for the new stack; repeats until the length is 1.

#### Process
1. First do the construction of the maximum stack of built Max Heap(a), convert any array to the maximum stack
2. From the last one, in the first and the last position in the second, and heapSize-1, remove from the stack the one that is currently deposited to the maximum value
3. ** HeapSize has been reduced by 1 **

#### Code
```java
public static void heapSort(double[] a) {
    buildMaxHeap(a);
    int heapSize = a.length - 1; // 这里的heapSize为最后一项的下标，下同
    
    for(int i = heapSize; i > 0; i--) { // 注意这里不必循环至第0项
        swap(a, 0, heapSize);
        heapSize--;
        maxHeapify(a, 0, heapSize);
    }
}

private static void maxHeapify(double[] a, int i, int heapSize) {
    // 找第i位与其左右子节点中最大者
    int l = i * 2 + 1;
    int r = i * 2 + 2;
    int largest = i;
    if(l <= heapSize && a[l] > a[largest]) {
        largest = l;
    }
    if(r <= heapSize && a[r] > a[largest]) {
        largest = r;
    }
    
    if(largest != i) {
        swap(a, largest, i);
        maxHeapify(a, largest, heapSize); // 这里是对largest为下标做最大堆化，此时largest下标为替换后的i
    }
}

private static void buildMaxHeap(double[] a) {
    int heapSize = a.length - 1; 
    // 从第一个不是叶子节点的下标开始，即 (heapSize - 1) / 2
    for(int i = (heapSize - 1) / 2; i >= 0; i--) {
        maxHeapify(a, i, heapSize);
    }
}

private static void swap(double[] a, int i, int j) {
    double temp = a[i];
    a[i] = a[j];
    a[j] = temp;
}
```
**Note **: Heapify uses a progressive idea but does not have to write a termination condition, because when it goes to the end of the element, the lower part of largest is the element itself, does not execute the last if statement, and it ends naturally.

#### Complexity analysis
 - Time complexity:$O(n\log n)$
 - Space complexity:$O(1)$

### Counting Sort

#### Thinking.
Non-comparison sort. Marks the frequency with the value of the element as an array down. The core is using auxiliary arrays.`C`, where`C[x]`Record Value`x`Number of occurrences. And then yes.`C`prefixes and determines the position of each number in the sequenced array. Applies to the sorting of integers with a smaller range of values.

#### Process
1. Find arrays`A`Maximum value`k`。
2. Create Size`k + 1`arrays`C`All over.`A`Count the frequency of occurrence of each number.
3. Yeah.`C`(c) Compute prefixes,`C[i]`is less than equal to`i`Number of elements, i.e. values`i`Endpoint index (1-based) in the output array.
4. Turn around.`A`(Secure stability)`A[j]`Release into result array`B`Other Organiser`C[A[j]] - 1`♪ And will ♪`C[A[j]]`Less 1.

#### Code
```java
private static int[] countingSort(int[] A) {
    int k = findMax(A);

    int[] B = new int[A.length];
    int[] C = new int[k + 1];
    // 统计频率
    for(int x : A) {
        C[x]++;
    }

    // 计算累加频次（前缀和）
    // C[i] 现在表示 <= i 的元素总数
    for(int i = 1; i < k + 1; i++) {
        C[i] += C[i-1]; 
    }

    // 反向遍历构建输出数组 B
    for(int j = A.length - 1; j >= 0; j--) {
        B[C[A[j]] - 1] = A[j]; // 放入 B 中正确位置
        C[A[j]]--;             // 该位置已被占用，前移一位
    }
    
    return B;
}

private static int findMax(int[] A) {
    int max = Integer.MIN_VALUE;
    for(int x : A) {
        max = Math.max(max, x);
    }
    return max;
}
```

#### Complexity analysis
 - Time complexity:$O(n + k)$
 - Space complexity:$O(n + k)$
 - Feature: Stable Sorting, applicable to`k`Not much.

### Sort Base (Radix Sort)

#### Thinking.
Non-comparison sort. Cuts the whole number into a different number and then compares it separately to each number.
It is common for each person to be steadily sequenced (e.g. counting or barrel sequencing) from the lowest level, following the LSD, Least Significant Digit strategy. When the highest ranking is completed, the columns become orderly sequences.
*Note: This code example uses the binary Radix Sorting of the base number of binary bits, 1 bit (0 or 1) for each check, with a total of 32 cycles (digits corresponding to int). This is essentially sorting the numbers as 32 bits of string 01. ♪ I'm sorry ♪

#### Process (in binary version)
1. Loop`i`0 to 31 (32 bits) corresponding to Java`int`length).
2. In every round.`i`, create two barrels (list)`a0`and`a1`。
3. Every number in a series`x`I'll tell you what.`i`Bit 0 or 1 (`x >> i & 1`)。
    - If 0, insert`a0`。
    - If yes 1, insert`a1`。
4. Will`a0`and`a1`in which the elements are put back in the original array and complete`i`bit of sort.
5. Repeat those steps to the top.

#### Code
```java
private static void radixSort(int[] arr) {
    // 对 int 的 32 个位依次进行排序
    for(int i = 0; i < 32; i++) {
        List<Integer> a0 = new ArrayList<>(); // 存放当前位为 0 的数
        List<Integer> a1 = new ArrayList<>(); // 存放当前位为 1 的数
        
        // 分桶
        for(int x : arr) {
            // 获取第 i 位的值 (0 或 1)
            int id = x >> i & 1;
            if(id == 0) a0.add(x);
            else a1.add(x);
        }
        
        // 合并回原数组
        // 先放 0 的桶
        for(int j = 0; j < a0.size(); j++) {
            arr[j] = a0.get(j);
        }
        // 再放 1 的桶
        for(int k = 0; k < a1.size(); k++) {
            arr[a0.size() + k] = a1.get(k);
        }
    }
}
```

#### Complexity analysis
 - Time complexity:$O(d \cdot n)$, where$d$is the maximum number of digits (32 here),$n$is the length of the array.
 - Space complexity:$O(n)$, additional barrel space is required for temporary storage data.
 - Characteristics: steady sequencing.
