## Stack

### Array-Based Stack

- Feature: Fixed length
- Member variable:`int[] data`, `int top`
- Function:`push()`, `pop()`

#### Code
```java
class Stack {
    private double[] data;
    private int top = -1;

    public Stack(int len) {
        data = new double[len];
    }

    public void push(double x) throws Exception{
        if(top == data.length - 1) throw new Exception("Stack Overflow!");
        data[++top] = x;
    }

    public double pop() throws Exception {
        if(top == -1) throw new Exception("Stack Underflow!");
        return data[top--];
    }
}
```

### Java `Stack` Class

#### Basic use methods

| Methodological signature | Description | Example |
| :---------------- | :--------------------------------------- | :------------------------------------ |
| `E push(E item)`| Pushs the element onto the top of the stack and returns the element. Zenium`stack.push(10);`                     |
| `E pop()`| Removes and returns the top element. Throws `EmptyStackException` if the stack is empty. | `int topElement = stack.pop();` |
| `E peek()`| Returns the top element without removing it. Throws `EmptyStackException` if the stack is empty. | `int topElement = stack.peek();` |
| `boolean empty()`| Returns `true` if the stack is empty. | `if (stack.empty()) { ... }` |
| `int search(Object o)`| Returns the element's 1-based position from the top, or `-1` if absent. | `int position = stack.search(20);` |

#### Example code
```java
import java.util.Stack;
import java.util.EmptyStackException;

public class StackExample {
    public static void main(String[] args) {
        Stack<Integer> stack = new Stack<>();

        // 1. push: 将元素压入栈顶
        stack.push(10);
        stack.push(20);
        stack.push(30);
        System.out.println("栈内容: " + stack); // 输出: 栈内容: [10, 20, 30] (注意这里是Vector的toString，栈顶在右侧)

        // 2. peek: 查看栈顶元素但不移除
        try {
            System.out.println("栈顶元素 (peek): " + stack.peek()); // 输出: 栈顶元素 (peek): 30
            System.out.println("栈内容 (peek后): " + stack); // 输出: 栈内容 (peek后): [10, 20, 30]
        } catch (EmptyStackException e) {
            System.out.println("栈为空，无法查看栈顶元素。");
        }

        // 3. pop: 移除并返回栈顶元素
        try {
            System.out.println("移除元素 (pop): " + stack.pop()); // 输出: 移除元素 (pop): 30
            System.out.println("栈内容 (pop后): " + stack); // 输出: 栈内容 (pop后): [10, 20]
        } catch (EmptyStackException e) {
            System.out.println("栈为空，无法移除元素。");
        }

        // 4. empty: 检查栈是否为空
        System.out.println("栈是否为空: " + stack.empty()); // 输出: 栈是否为空: false

        // 继续移除所有元素直至栈空
        while (!stack.empty()) {
            System.out.println("移除元素: " + stack.pop());
        }
        System.out.println("栈是否为空: " + stack.empty()); // 输出: 栈是否为空: true

        // 5. search: 搜索元素 (注意：1-based索引)
        stack.push(5); stack.push(15); stack.push(25);
        System.out.println("栈内容: " + stack);
        System.out.println("元素 15 的位置 (从栈顶算起，1-based): " + stack.search(15)); // 输出: 2
        System.out.println("元素 5 的位置: " + stack.search(5));   // 输出: 3
        System.out.println("元素 100 的位置: " + stack.search(100)); // 输出: -1 (未找到)
    }
}
```

    }

## Queue

### Group Simulation Queue
- Feature: Fixed length
- Member variable:`int[] data`, `int head`, `int tail`(All initially set to`-1`)
- Function:`enqueue()`, `dequeue()`

#### Code
```java
class Queue {
    private double[] data;
    private int head = -1;
    private int tail = -1;

    public Queue(int len) {
        data = new double[len];
    }
    public void enQueue(double x) throws Exception {

        if ((tail + 1) % data.length == head) {
            throw new Exception("Queue Overflow!");
        }

        if (head == -1) {
            head = 0;
        }

        tail = (tail + 1) % data.length;
        data[tail] = x;

    }

    public double deQueue() throws Exception {

        if (head == -1) {
            throw new Exception("Queue Underflow!");
        }

        double x = data[head];
        if (head == tail) {
            head = -1;
            tail = -1;
        } else {
            head = (head + 1) % data.length;
        }

        return x;
    }
}
```

### Java `Queue`Interface
Because`Queue`It's an interface. It's not a direct example. It's usually used.`LinkedList`As its realization class.

#### Basic use methods

| Methodological signature | Description | Example |
| :--- | :--- | :--- |
| `boolean offer(E e)`| Inserts elements into the end of the queue. If insert successfully returns`true`。 | `queue.offer(10);` |
| `E poll()`| Removes and returns elements in the front of the queue. If the team is empty, return.`null`。 | `Integer head = queue.poll();` |
| `E peek()`| Returns elements in the front of the queue, but does not remove them. If the team is empty, return.`null`。 | `Integer head = queue.peek();` |
| `boolean isEmpty()`Check if the queue is empty (inheritance from Colletion). If empty, return`true`。 | `if (queue.isEmpty()) { ... }` |
| `boolean add(E e)`| Inserts elements into the end of the queue. If you return successfully`true`, if no space is available, throw it out`IllegalStateException`。 | `queue.add(20);` |

#### Example code

```java
import java.util.LinkedList;
import java.util.Queue;

public class QueueExample {
    public static void main(String[] args) {
        // 注意：Queue 是接口，通常使用 LinkedList 作为实现类
        Queue<Integer> queue = new LinkedList<>();

        // 1. add: 将元素添加到队尾
        queue.add(10);
        queue.add(20);
        queue.add(30);
        System.out.println("队列内容: " + queue); // 输出: 队列内容: [10, 20, 30] (左侧是队头，右侧是队尾)

        // 2. peek: 查看队头元素但不移除
        Integer headPeek = queue.peek();
        if (headPeek != null) {
            System.out.println("队头元素 (peek): " + headPeek); // 输出: 队头元素 (peek): 10
        } else {
            System.out.println("队列为空 (peek)");
        }
        System.out.println("队列内容 (peek后): " + queue); // 输出: 队列内容 (peek后): [10, 20, 30]

        // 3. poll: 移除并返回队头元素 (FIFO: 先进先出)
        Integer headPoll = queue.poll();
        System.out.println("移除元素 (poll): " + headPoll); // 输出: 移除元素 (poll): 10
        System.out.println("队列内容 (poll后): " + queue); // 输出: 队列内容 (poll后): [20, 30]

        // 4. isEmpty: 检查队列是否为空
        System.out.println("队列是否为空: " + queue.isEmpty()); // 输出: 队列是否为空: false

        // 继续移除所有元素
        while (!queue.isEmpty()) {
            System.out.println("处理并移除: " + queue.poll());
        }
        System.out.println("队列是否为空: " + queue.isEmpty()); // 输出: 队列是否为空: true
    }
}
```

## Queue Implemented with Stacks

### Version 1: Enqueue `O(1)`
![](https://raw.githubusercontent.com/Ferdinandhu000/my_blog_img/master/20251210104349.png)
#### Structure
- `inbox`: Direct storage`enqueue`Elements
- `outbox` stores elements moved from `inbox`; its top element is dequeued first.

#### Process
`inbox`Direct Receiving`enqueue`Elements.`dequeue`Let's see.`outbox`Are there elements in it, and if so, directly`pop`Yeah, if...`outbox`empty, in order`inbox`Elements in`pop`Present.`outbox`Medium

#### Code
```java
class QueueOnStack_v1 {
    private Stack<Double> inBox = new Stack<Double>();
    private Stack<Double> outBox = new Stack<Double>();

    public void enQueue(double x) {
        inBox.push(x);
    }

    public double deQueue() {
        if(outBox.isEmpty()) {
            while(!inBox.isEmpty()) outBox.push(inBox.pop());
        }
        return (double)outBox.pop();
    }
}
```

### Version 2: Dequeue `O(1)`
![](https://raw.githubusercontent.com/Ferdinandhu000/my_blog_img/master/20251210104630.png)
#### Structure
- `in_outBox`: Keep the structure of the queue at all times, i.e. the top elements are`dequeue`Object
- `auxiliary`: Auxiliary switching`in_outBox`Central element, temporary storage`in_outBox`Elements

#### Process
`enqueue`Time to judge.`in_outBox`if there are no elements, if there are no elements (to be inserted in the first element)`push`In.`in_outBox`I don't know. If there are elements, first`in_outBox`Element emptied, temporarily stored.`auxiliary`Medium, again`push`To save element in`in_outBox`Finally.`dequeue`Time, direct`pop`Out`in_outBox`The top element in it.

#### Code
```java
class QueueOnStack_v2 {
    private Stack<Double> in_outBox = new Stack<Double>();
    private Stack<Double> auxiliary = new Stack<Double>();

    public void enQueue(double x) {
        if(in_outBox.isEmpty()) in_outBox.push(x);
        else {
            while(!in_outBox.isEmpty()) {
                auxiliary.push(in_outBox.pop());
            }
            in_outBox.push(x);
            while(!auxiliary.isEmpty()) {
                in_outBox.push(auxiliary.pop());
            }
        }
    }

    public double deQueue() {
        return (double)in_outBox.pop();
    }

}
```

class StackOnQueue_v1 {
    private Queue<Double> q1 = new LinkedList<>();
    private Queue<Double> q2 = new LinkedList<>();

    public void push(double x) {
        q1.add(x);
    }

    public double pop() {
        while(q1.size() - 1 != 0) {
            q2.add(q1.poll());
        }
        double x = q1.poll();
        q1.clear();
        while(!q2.isEmpty()) {
            q1.add(q2.poll());
        }
        return x;
    }
}

## LinkedList
### Node()`Node`)
#### Composition
- Value`val`

#### Code

class Node {
    int val;
    Node prev;
    Node next;

    public Node(int x) {

### Doubly Linked List with a Sentinel Node
#### Characteristics
- Organisation`Sentinel`Sentry node.`nil`
- Initialization phase`nil`The nodes point to themselves before and after.

#### Code
```java
class LinkedNodeSentinel {
    Node nil;

    public LinkedNodeSentinel () {
        nil = new Node(-1);
        nil.prev = nil;
        nil.next = nil;
    }

    // Sentinel的插入操作是插在nil节点后
    // 先搭建x的后向连接(x.next & nil.next.pre)，再搭建x的前向连接(nil.next & x.prev)
    public void insert(Node x) {
        x.next = nil.next;
        nil.next.prev = x;
        nil.next = x;
        x.prev = nil;
    }

    public Node search(int x) {
        Node n = nil.next; // 从nil.next开始寻找
        // 如果找到或者回到nil则循环停止
        while(n != nil && n.val != x) {
            n = n.next;
        }
        if(n == nil) {
            System.out.println(" Value Not Found!");
        }
        return n;
    }

    public void delete(int x) {
        Node n = search(x);
        if(n == nil) {
            return;
        }
        // 记得要重新搭建连接
        n.prev.next = n.next;
        n.next.prev = n.prev;
    }

    public boolean isEmpty() {
        if(nil.next == nil) return true;
        return false;
    }

    @Override
    public String toString() {
        String s = "";
        Node n = nil.next;
        while(n != nil) {
            s += n.val + " ";
            n = n.next;
        }
        return s;
    }
}
```
